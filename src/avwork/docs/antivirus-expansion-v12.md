# Egret v12 AV Expansion

This pack adds the first integrated antivirus and network-protection baseline to the v12 app:
- file events
- malware verdicts
- quarantine records
- URL reputation / phishing-style web checks
- Files / Threats / Quarantine / Protection API and dashboard surfaces

The scan engine is intentionally lightweight and deterministic for repeatable tests.
It is a foundation for AV1, not a complete production antivirus engine.
